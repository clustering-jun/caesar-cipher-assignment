# 정보보안(001분반) 과제
## 시저암호화 과제
### 경상국립대학교 AI정보공학과 박정준(2025013989)

본 프로그램은 시저 암호 알고리즘을 이용하여 사용자가 입력한 평문을 암호화한다. ord() 함수를 통해 알파벳을 ASCII 코드로 변환하고, 입력받은 암호화 키만큼 값을 이동시킨다. 이때 % 26 연산을 이용하여 알파벳 범위를 초과하면 처음으로 돌아오도록 구현하였다. 대문자와 소문자는 각각 다른 ASCII 코드 범위를 적용하며, 공백과 기타 문자는 변경하지 않고 유지한다. 최종적으로 chr() 함수를 이용하여 변환된 ASCII 코드를 문자로 복원한 후 암호문을 출력한다.
